# LINE Harness 公式LINE説明会 スライド構成案

作成日: 2026-08-28

## 目的

LINE Harness の使い方と仕組みを、経営者・運用担当・営業担当が相手に説明できる状態にする。単なる機能紹介ではなく、「LINE公式アカウントをどう設計し、どう運用し、裏側で何が自動処理されるか」が伝わる説明会資料にする。

## 想定聴衆

- LINE公式アカウントを集客・教育・予約・販売に使いたい事業者
- Lステップ、UTAGE、その他LINE CRMからの移行を検討している人
- 社内でLINE運用の仕組みを説明する必要がある人
- AIや自動化をLINE運用に組み込みたい人

## 1. 表紙

タイトル: LINE Harness 公式LINE運用説明会

サブタイトル: 友だち管理・配信・自動化・予約・分析を自社で持てるLINE CRM

話すこと:
- LINE Harness は、LINE公式アカウントの運用を自社管理できるオープンソースCRM。
- Cloudflare上で動き、LINEのWebhook、Messaging API、LIFFをまとめて扱える。

## 2. LINE Harnessとは

キーメッセージ:
- LINE公式アカウントを「配信ツール」ではなく「顧客管理・自動化基盤」に変える仕組み。

載せる内容:
- 友だち管理
- タグ・セグメント管理
- ステップ配信
- 一斉配信・予約配信
- 自動返信
- リッチメニュー切替
- LIFFフォーム
- 予約管理
- トラッキングリンク
- スコアリング
- マルチアカウント管理
- AI連携、SDK、MCP Server

## 3. 何を解決するか

課題:
- LINE公式アカウント標準機能だけでは、細かい顧客管理や自動分岐が弱い。
- 既存SaaSは月額費用、データの囲い込み、API制限、AI連携の難しさがある。
- 配信、反応、予約、成約データがバラバラになりやすい。

LINE Harnessでできること:
- 顧客データを自社のD1データベースに保持する。
- 行動に応じてタグ、シナリオ、リッチメニュー、通知を自動変更する。
- クリック、フォーム回答、予約、CVを一連の流れで追跡する。
- AIや外部システムからAPI経由で操作できる。

## 4. 全体像

図として載せる構成:

```text
ユーザーのLINE
  ↓ 友だち追加・メッセージ・クリック・フォーム回答
LINE Platform
  ↓ Webhook
Cloudflare Worker API
  ↓ 保存・判定・自動処理
Cloudflare D1 Database
  ↑
管理画面 / LIFF / SDK / Claude Code
```

話すこと:
- ユーザーのLINE上の行動がWebhookでWorkerに届く。
- Workerが友だち情報、タグ、配信履歴、クリック、フォーム回答をD1に保存する。
- 管理者はNext.jsの管理画面から設定・配信・分析を行う。
- LIFFにより、LINEアプリ内でフォームや予約が完結する。

## 5. 基本の使い方

運用の基本手順:
1. LINE公式アカウントとLINE Developersを用意する。
2. LINE HarnessをCloudflareにセットアップする。
3. 管理画面にログインする。
4. 友だち追加導線を作る。
5. タグ、シナリオ、フォーム、リッチメニューを設定する。
6. テスト配信してから本番運用する。
7. クリック、回答、予約、CVを見て改善する。

説明ポイント:
- 運用者は基本的に管理画面を操作する。
- エンジニアやAIはAPI、SDK、MCP Serverから同じ機能を操作できる。

## 6. 友だち管理

載せる内容:
- Webhookで友だち追加を自動検知
- LINEプロフィールを取得
- friendsテーブルに登録
- タグ、メタデータ、流入経路、フォロー状態を管理
- 複数LINEアカウントでもUUIDで同一人物を紐付ける設計

説明例:
- 「誰が友だち追加したか」
- 「どこから流入したか」
- 「どのタグを持っているか」
- 「どのシナリオを進行中か」
- 「予約・フォーム回答・クリック履歴があるか」

## 7. タグとセグメント

キーメッセージ:
- タグはLINE運用の分岐スイッチ。

使い方:
- 友だち追加時にタグ付け
- フォーム送信時にタグ付け
- リンククリック時にタグ付け
- 購入・予約・CV発生時にタグ付け
- タグを条件に配信対象を絞る
- タグを条件にシナリオやリッチメニューを切り替える

## 8. ステップ配信

キーメッセージ:
- シナリオは「いつ、誰に、何を送るか」を自動化する機能。

トリガー:
- 友だち追加
- タグ追加
- 手動登録

できること:
- 即時配信
- 数分後、1日後、3日後などの遅延配信
- 条件分岐
- テキスト、画像、Flexメッセージ
- 配信ログ保存

例:
```text
友だち追加
  → すぐに挨拶
  → 1日後にサービス説明
  → 3日後に事例紹介
  → クリックした人だけ相談案内
```

## 9. 一斉配信・予約配信

キーメッセージ:
- 全員向け告知だけでなく、タグや条件で絞った配信ができる。

載せる内容:
- 下書き
- 即時配信
- 予約配信
- タグ配信
- セグメント配信
- 500件単位のバッチ処理
- 成功件数、対象件数、配信ステータス

## 10. 自動返信とチャット

載せる内容:
- キーワード完全一致・部分一致で自動返信
- ユーザーからのメッセージをmessages_logに記録
- 管理画面から1対1返信
- 未返信Inboxで対応漏れを見つける
- 自動配信と有人対応を切り分ける

説明ポイント:
- よくある質問は自動返信。
- 個別相談はチャットで有人対応。
- 未返信一覧で放置を防ぐ。

## 11. リッチメニュー

キーメッセージ:
- LINEの下部メニューをユーザー状態に応じて変えられる。

使い方:
- デフォルトメニューを作る
- 画像をアップロードする
- タップ領域を設定する
- URL、メッセージ、postback、メニュー切替を割り当てる
- タグや自動化でユーザー別メニューに切り替える

例:
- 新規ユーザー: はじめての方向けメニュー
- 申込済みユーザー: 予約確認・資料閲覧メニュー
- VIPユーザー: 限定導線メニュー

## 12. LIFFフォーム・予約

キーメッセージ:
- LINEアプリ内でフォーム回答や予約が完結する。

フォームでできること:
- 名前、メール、電話番号、選択肢、自由記述などを収集
- 回答を友だちデータに保存
- 送信時にタグ付け
- 送信時にシナリオ開始

予約でできること:
- Google Calendarの空き枠を表示
- 友だちがLINE内で日時選択
- 予約情報を保存
- リマインダー配信につなげる

## 13. トラッキングリンク

キーメッセージ:
- URLクリックを「誰が押したか」まで追える。

できること:
- クリック数の計測
- LINEアプリ内ではLIFF経由で友だちを特定
- クリック時にタグ付け
- クリック時にシナリオ登録
- 広告、LP、セミナー、販売ページへの反応を見える化

例:
```text
セミナーLPをクリック
  → 「セミナー興味あり」タグ付与
  → 申込促進シナリオ開始
  → 管理画面でクリック履歴を確認
```

## 14. オートメーション

キーメッセージ:
- LINE内の行動をきっかけに、IF-THENで次の処理を自動実行する。

イベント例:
- 友だち追加
- メッセージ受信
- タグ変更
- スコア到達
- CV発生
- 予約完了
- 外部Webhook受信

アクション例:
- タグ付与・削除
- シナリオ開始
- メッセージ送信
- Webhook送信
- リッチメニュー切替
- メタデータ更新

## 15. スコアリング・CV・アフィリエイト

載せる内容:
- クリック、回答、予約、購入などの行動をスコア化
- 見込み度の高い友だちを抽出
- CVポイントを管理
- アフィリエイトリンク発行
- クリック、友だち追加、CVを時系列で記録
- 成果承認、報酬確定、通知

説明ポイント:
- 配信だけでなく、売上や成果に近い行動まで追える。

## 16. マルチアカウント・BAN対策

キーメッセージ:
- 複数のLINE公式アカウントを1つの管理画面で扱える。

載せる内容:
- アカウント別の友だち、タグ、配信
- UUIDで同一人物を横断管理
- トラフィックプールで流入を複数アカウントへ振り分け
- 5分ごとのヘルスチェック
- 403や大量送信などのリスク検知

注意:
- BAN回避を保証する機能ではなく、アカウント状態の監視と運用リスク低減のための仕組みとして説明する。

## 17. AI連携

キーメッセージ:
- LINE HarnessはAIから操作できるLINE CRM。

載せる内容:
- 全機能にAPIがある
- TypeScript SDKがある
- MCP ServerによりClaude Codeから操作できる
- 会話確認、シナリオ作成、配信作成、タグ管理などを自然言語で支援できる

説明ポイント:
- AIが勝手に送信しないよう、配信やメッセージ送信は確認フローを前提にする。
- AIは運用補助、分析、原稿作成、設定作成に強い。

## 19. 代表的な運用フロー

### セミナー集客

```text
広告・SNS投稿
  → トラッキングリンク
  → 友だち追加
  → ウェルカムシナリオ
  → LIFF申込フォーム
  → 申込済みタグ
  → 事前リマインダー
  → 当日案内
  → 参加後フォロー
  → CV計測
```

### 個別相談

```text
リッチメニュー
  → 予約LIFF
  → Google Calendar空き枠表示
  → 予約確定
  → 担当者通知
  → 予約前リマインダー
  → チャットで個別対応
```

### 商品販売

```text
ステップ配信
  → 商品LPクリック
  → 興味ありタグ
  → 追加説明シナリオ
  → 購入CV
  → 購入者タグ
  → 購入者用リッチメニュー
```

## 20. 導入・運用に必要なもの

必要なもの:
- Cloudflareアカウント
- LINE公式アカウント
- LINE DevelopersのMessaging APIチャネル
- LINE Loginチャネル
- LIFFアプリ
- Node.js、pnpm
- 管理者用APIキー

セットアップ:
- `npx create-line-harness` でセットアップ可能
- D1データベース作成
- Workerと管理画面をデプロイ
- LINE Webhook URLを設定
- LIFFとLINE Loginを設定

## 21. 既存SaaSとの違い

比較軸:
- 月額費用: SaaS課金ではなくCloudflare中心の自社運用
- データ所有: D1に保存され、自社で扱える
- API: 全機能を外部から操作可能
- AI連携: MCP ServerとSDKを前提にした設計
- カスタマイズ: OSSなので拡張できる
- マルチアカウント: 複数公式LINEの管理を標準設計

## 22. まとめ

締めのメッセージ:
- LINE Harnessは、LINE公式アカウントを「配信」「CRM」「自動化」「計測」「AI連携」まで含めて自社運用するための基盤。
- 運用者は管理画面で設定し、ユーザーはLINE上で自然に反応し、裏側ではWebhook、D1、Cron、LIFF、Messaging APIが動く。
- 説明するときは「友だちの行動 → データ化 → タグやシナリオで自動対応 → 結果を見て改善」という流れで伝える。

## 付録: 1分説明

LINE Harnessは、LINE公式アカウントを本格運用するためのオープンソースCRMです。友だち管理、タグ、ステップ配信、一斉配信、自動返信、リッチメニュー、フォーム、予約、クリック計測、CV計測までを一つの管理画面で扱えます。ユーザーが友だち追加、メッセージ送信、リンククリック、フォーム回答、予約をすると、その行動がWebhookやLIFFを通じてCloudflare Workerに届き、D1データベースに保存されます。そのデータをもとに、タグ付け、シナリオ開始、リッチメニュー切替、通知、リマインダーなどを自動実行できます。既存SaaSと違い、自社のデータとして持てて、APIやAIからも操作できるのが特徴です。
