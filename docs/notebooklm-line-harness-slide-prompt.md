# NotebookLM用プロンプト: LINE Harness説明会スライド作成

以下をNotebookLMに貼り付けてください。資料ソースとして、README、docs/wiki、docs/manual、必要であれば管理画面スクリーンショットを一緒にアップロードすると精度が上がります。

```text
あなたはBtoB SaaS、LINE公式アカウント運用、CRM、自動化ツールに詳しいプレゼン資料作成者です。

添付資料をもとに、「LINE Harness 公式LINE運用説明会」のスライド資料を作成してください。

目的:
- LINE Harnessの使い方と仕組みを、社長・営業担当・運用担当が相手に説明できる状態にする。
- 技術者だけでなく、非エンジニアにも伝わるようにする。
- ただの機能一覧ではなく、「ユーザーのLINE上の行動が、裏側でどのようにデータ化・自動処理されるか」を説明する。
- Lステップ、UTAGEなどの既存LINE CRMとの違いも説明できるようにする。

想定聴衆:
- LINE公式アカウントを集客、教育、予約、販売、顧客管理に使いたい事業者
- 既存LINE CRMの費用や制限に課題を感じている人
- 自社でLINE運用基盤を持ちたい経営者、マーケター、運用担当者
- AIをLINE運用に組み込みたい人

資料のトーン:
- 日本語
- 経営者にも分かる言葉
- 専門用語は出してよいが、必ず簡単な説明を添える
- 売り込みすぎず、仕組みと運用価値が伝わる説明
- 「何ができるか」「どう使うか」「裏側で何が起きるか」を対応させる

スライド枚数:
- 18〜24枚程度
- 1枚につきメッセージは1つ
- 箇条書きは多くても5項目まで
- 図解できる箇所は図解案を入れる
- 各スライドに「話す内容」も付ける

必ず含める章:

1. 表紙
タイトル: LINE Harness 公式LINE運用説明会
サブタイトル: 友だち管理・配信・自動化・予約・分析を自社で持てるLINE CRM

2. LINE Harnessとは
- LINE公式アカウントをCRM、自動化、計測、AI連携まで拡張するオープンソース基盤
- Cloudflare Workers、D1、Next.js管理画面、LIFF、LINE Messaging APIで構成される

3. 解決する課題
- LINE公式アカウント標準機能だけでは顧客管理・分岐・計測が弱い
- 既存SaaSは月額費用、データロックイン、API制限、AI連携の難しさがある
- 配信、予約、フォーム、クリック、CVがバラバラになりやすい

4. 全体像
以下の流れを図解する:
ユーザーのLINE → LINE Platform → Cloudflare Worker → D1 Database → 管理画面 / LIFF / SDK / Claude Code

5. 基本の使い方
- LINE公式アカウントとLINE Developersを用意
- Cloudflareにセットアップ
- 管理画面にログイン
- タグ、シナリオ、フォーム、リッチメニューを作る
- テストして本番配信
- 結果を見て改善

6. 友だち管理
- 友だち追加をWebhookで自動検知
- LINEプロフィール、フォロー状態、タグ、メタデータ、流入経路を管理
- 複数LINEアカウントでもUUIDで同一人物を横断管理できる設計

7. タグとセグメント
- タグはユーザー状態を表すラベル
- タグで配信対象、シナリオ、リッチメニュー、自動化を分岐
- クリック、フォーム送信、予約、CVなどの行動でタグを自動付与できる

8. ステップ配信
- 友だち追加、タグ追加、手動登録をきっかけにメッセージを順番に送る
- 即時配信、遅延配信、条件分岐ができる
- 例: 友だち追加 → 挨拶 → 1日後に説明 → 3日後に事例 → クリック者だけ相談案内

9. 一斉配信・予約配信
- 全員配信、タグ配信、セグメント配信
- 下書き、即時、予約
- バッチ処理、成功件数、対象件数、ステータス管理

10. 自動返信と有人チャット
- キーワードに応じた自動返信
- メッセージ履歴を保存
- 管理画面から1対1返信
- 未返信Inboxで対応漏れを防ぐ

11. リッチメニュー
- LINE下部メニューを管理
- デフォルトメニュー、ユーザー別メニュー、タグ別メニュー切替
- URL、メッセージ、postback、リッチメニュー切替を設定できる

12. LIFFフォーム
- LINEアプリ内でフォーム回答が完結
- 名前、メール、電話、選択肢、自由記述などを収集
- 回答を友だちデータに保存
- 送信時にタグ付け、シナリオ開始ができる

13. 予約機能
- LIFF上で予約導線を作れる
- Google Calendar連携で空き枠を表示
- 予約後のリマインダーや担当者通知につなげられる

14. トラッキングリンク
- URLクリックを計測
- LINEアプリ内ではLIFF経由で誰が押したかを特定
- クリック時にタグ付け、シナリオ登録ができる
- 広告、LP、セミナー、販売ページの反応が見える

15. オートメーション
- IF-THENルールで自動処理
- イベント例: 友だち追加、メッセージ受信、タグ変更、スコア到達、CV、予約、外部Webhook
- アクション例: タグ付与、シナリオ開始、メッセージ送信、Webhook送信、リッチメニュー切替、メタデータ更新

16. スコアリング・CV・アフィリエイト
- 行動に点数をつけて見込み度を可視化
- CVポイントを管理
- アフィリエイトリンク、クリック、友だち追加、CV、成果承認、報酬通知まで扱える

17. マルチアカウント・BAN対策
- 複数LINE公式アカウントを1つの管理画面で管理
- アカウントごとに友だち、タグ、配信を管理
- 5分ごとのヘルスチェックでリスクを監視
- 注意: BAN回避を保証するものではなく、状態監視と運用リスク低減の仕組みとして説明する

18. AI連携
- API、SDK、MCP ServerによりAIから操作できる
- Claude Codeから会話確認、シナリオ作成、配信作成、タグ管理などを支援
- 送信系操作は確認フローを前提にし、安全に運用する

19. 管理画面の主なメニュー
- accounts, friends, chats, broadcasts, scenarios, auto-replies, automations, rich-menus, inflow-links, forms, form-submissions, events, booking, scoring, conversions, affiliates, reminders, notifications, health
- それぞれ何をする画面かを1行で説明

20. 代表的な運用フロー
以下3つを図解する:
- セミナー集客: 広告/SNS → トラッキングリンク → 友だち追加 → ステップ配信 → LIFF申込 → リマインダー → 参加後フォロー → CV計測
- 個別相談: リッチメニュー → 予約LIFF → Google Calendar → 予約確定 → 通知 → リマインダー → チャット対応
- 商品販売: ステップ配信 → LPクリック → 興味ありタグ → 追加説明 → 購入CV → 購入者タグ → 購入者用メニュー

21. 既存SaaSとの違い
- 月額費用
- データ所有
- API公開
- AI連携
- カスタマイズ性
- マルチアカウント
- OSSであること

22. まとめ
- LINE Harnessは、LINE公式アカウントを「配信」「CRM」「自動化」「計測」「AI連携」まで含めて自社運用するための基盤
- 説明の基本構造は「友だちの行動 → データ化 → タグやシナリオで自動対応 → 結果を見て改善」

出力形式:
- スライド番号
- スライドタイトル
- スライド本文
- 図解案
- 話す内容
- 必要なら補足メモ

重要な注意:
- LINE Harnessが公式に保証していないことは断定しない。
- BAN対策は「検知・監視・運用リスク低減」として説明し、「必ずBANされない」とは書かない。
- Cloudflare無料枠で動く可能性があるが、利用量や構成により費用が発生する可能性があるため、「低コスト」「無料枠で始めやすい」という表現にする。
- 技術構成は深掘りしすぎず、経営者向けには価値、運用担当向けには操作、技術者向けには仕組みが分かるバランスにする。
```
